# 🎓 Student Result Management System

A web-based **Student Result Management System** developed to simplify the management, storage, and processing of student academic records and examination results.

The system provides an easy-to-use interface for managing student information and academic results while providing authenticated access to the application.

---

- 🔐 User Authentication
- 👨‍🎓 Student Record Management
- 📚 Academic Record Management
- 📊 Result Management
- 🔎 Easy Access to Student Results
- 🖥️ User-Friendly Interface

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/harsh181004/Student-Result-Management-System.git
```

### 2. Move the Project to XAMPP

Download and install **XAMPP** if you don't already have it.

Move the cloned project folder into:

```text
xampp/htdocs/
```

### 3. Start Apache and MySQL

Open the **XAMPP Control Panel** and start:

- Apache
- MySQL

### 4. Setup the Database

1. Open your browser.
2. Go to `http://localhost/phpmyadmin/`
3. Create a new database.
4. Import the SQL file available in the project's **SQL File** folder.
5. Make sure the database configuration in the PHP files matches your local MySQL configuration.

### 5. Run the Project

Open your browser and visit:

```text
http://localhost/Student-Result-Management-System/
```

The application should now be running on your local machine.
